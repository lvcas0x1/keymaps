Karabiner-Elements

Modifier remap
Caps LockRemaps to ⌃⌥⌘ (Control + Option + Command) used as Hammerspoon's Hyper key

Hammerspoon

Launcher — Hyper = ⌃⌥⌘
⌃⌥⌘WFocus or launch WezTerm
⌃⌥⌘WOpen a new WezTerm window bound to the same hotkey as above
Window layout
⌘←Snap left half hops one screen east if already there
⌘→Snap right half hops one screen west if already there
⌘↑Maximize window
⌘↓Center window keeps current size

WezTerm

Tabs
⌃NNew tab
⌃WClose tab (disabled when it's the only tab)
⌃←Previous tab
⌃→Next tab
Panes
⌃,Focus previous pane
⌃.Focus next pane
⌃=Split horizontally — new pane below
⌃-Split vertically — new pane on the right
⌃QClose pane (disabled when it's the only pane)
Pane resize
⌃⇧↑Grow pane upward
⌃⇧↓Grow pane downward
⌃⇧←Grow pane leftward
⌃⇧→Grow pane rightward
